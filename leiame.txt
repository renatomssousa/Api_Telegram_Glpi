6. Comandos do dia a dia

Iniciar:

sudo systemctl start glpi-api.service glpi-monitor.service

Parar:

sudo systemctl stop glpi-api.service glpi-monitor.service

Reiniciar:

sudo systemctl restart glpi-api.service glpi-monitor.service

Subir automático no boot:

sudo systemctl enable glpi-api.service glpi-monitor.service

Observação importante:
no service do uvicorn não use --reload, porque isso é só para desenvolvimento.

Antes de iniciar, confirme se esses arquivos existem:

ls /home/glpi/Api_Telegram_Glpi
ls /home/glpi/Api_Telegram_Glpi/venv/bin/uvicorn
ls /home/glpi/Api_Telegram_Glpi/venv/bin/python
